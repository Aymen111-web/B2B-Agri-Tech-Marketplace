# Category Images Directory

Place your custom category produce images here.
Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`.

Recommended naming conventions:
- `fruits.png` or `fruits.jpg`
- `vegetables.png` or `vegetables.jpg`
- `coffee.png` or `coffee.jpg`
- `grains.png` or `grains.jpg`
- `spices.png` or `spices.jpg`
- `oilseeds.png` or `oilseeds.jpg`
- `pulses.png` or `pulses.jpg`

The application will automatically detect and display these category images!
When a farmer uploads their own photo for a crop listing, the uploaded photo will always be displayed on the crop card.
